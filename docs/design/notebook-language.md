# Wonderloom 正式视觉语言 · 纸上的光

适用于正式页面。视觉基准是 `try/loom` 的实际页面及 `scratchpad/explore-loom-direction/assets/loom/` 截图；`/directions/` 继续作为隔离的历史试样。2026-10-23 作者明确否决浅绿版本，要求原样沿用 `try/loom` 的配色和主要版式。此裁决优先于此前的设计结项报告。

## 材料与色值

`src/styles/tokens.css` 是正式页面的唯一权威。以下值取自 `try/loom:src/styles/loom-try.css`，不另行调色：

| 材料 | 色值 | 用途 |
| --- | --- | --- |
| 纸 | `#F4EFE1` | 页面底色，沿用原型的 `grain.png` 纸纹 |
| 浅纸 | `#FAF7EC` | 次级纸面 |
| 深纸 | `#E9E1CD` | 极少量衬底 |
| 墨 | `#23282E` | 正文、边框及主标题 |
| 朱 | `#B03A2E` | 首页小标、页尾「佳杰」印、当前态、编号等小面积强调 |
| 靛 | `#2C4A63` | 文字链接 |
| 金 | `#C79A3A` | 交织曲线等非承重装饰；不在浅纸上承担正文对比度 |

边线用原型墨色透明度，图像白边沿用原型的纸片处理。不要重新引入浅绿配色、渐变底、玻璃效果或通用圆角卡片。宋体承担标题和长文，黑体承担导航与操作，楷体仅用于极短的手写感标记，等宽用于编号与来源。

颜色按语义分配：墨色承载阅读，淡墨承载辅助信息；靛色标出可读的文字链接；朱色标出身份、编号、当前阅读位置及少量动作反馈；金色只留在交织曲线。不要仅靠朱色区分链接或状态，当前页还有边线、当前目录还有左边框。新增页面先复用这些角色，不为单页另配颜色。

## 字体与字阶

正式站点只用 `tokens.css` 中的字阶。中文宋体依次回退到 Songti SC、Noto Serif CJK SC 和系统 serif；拉丁衬线优先 Baskerville。黑体使用系统字体栈；楷体只用于副署与「佳杰」印；等宽只用于编号、来源和极短的小标。当前没有内嵌网络字体，跨操作系统的字形与换行可能不同，应以真实设备复核。

| 角色 / token | 桌面 → 窄屏 | 字重 / 行高 | 使用范围 |
| --- | --- | --- | --- |
| 展示 `--type-display` | 32–52 px；≤500 为 32 px，≤360 为 29 px | 宋体 600 / 1.44 | 仅首页首屏标题 |
| 页题 `--type-page` | 30–44 px | 宋体 600 / 1.42 | 内页唯一主标题，包括文章 |
| 节题 `--type-section` | 24–32 px | 宋体 600 / 1.45 | 页面一级内容分区、文章 h2 |
| 条目 `--type-entry` | 20–25 px | 宋体 600 / 1.45 | 文章卡/系列/路径标题、文章 h3 |
| 导语 `--type-lead` | 18 px | 宋体 400 / 1.9 | 页题后的短导语、收束段 |
| 长文 `--type-reading` | 17.5 px；≤600 为 16.5 px | 宋体 400 / 1.92 | 作者文章正文 |
| 正文 `--type-body` | 17 px | 宋体 400 / 1.9 | 普通叙述、索引摘要 |
| 操作 `--type-ui` | 14 px | 黑体 400 / 1.6 | 导航、链接动作、按钮、面包屑；当前目录 600 |
| 辅助 `--type-caption` | 13 px | 黑体 400 / 1.7 | 图注、说明、脚注、目录条目 |
| 注记 `--type-note` | 11 px | 等宽 400 / 1.6 | 编号、来源、短标签；不得承担操作或连续阅读 |

品牌字 22 px 宋体 400；方印 19 px 楷体 400（≤500 为 16 px），只用于固定身份元素。标题统一 600，不按页面临时选 500 或 700。字号的 `clamp()` 是同一字阶的连续响应，并非额外层级。行高从 `--leading-*` 取值；品牌字和方印因固定形态单独处理。新需求先判定文字的**阅读角色**，不能以“此处放不下”为由新增字号。

## 网格、留白与空间不足

- 外框最大 1320 px，内容最大 1216 px；桌面页边距 52 px，≤760 为 24 px，≤680 为 20 px。内页用 110 px 侧栏加 34 px 栏距，≤760 改单栏。作者文章正文最多 700 px，并相对整张纸居中；左侧目录不改变正文轴线。
- 首页首屏保留 `try` 的 1.06 / 0.94 双栏，≤760 改单栏；内容索引用编号、标题/摘要、动作的网格，空间不足时动作移到下一行。章节目录在≤760 纵向堆叠标签、完整标题和去向。文章分页在≤500 从双栏改单栏。
- 作者长文宽度不超过正文轴线；分区留白由 `--home-section-space`、`--content-section-space`、`--article-section-space` 等语义变量控制。用版面宽度和间距解决拥挤，不缩小条目标题或正文来塞进一行。
- 标题、导航、目录、摘要、来源和图注保留全文，优先自然换行；窄屏收起并列栏、再换行。长英文词和 URL 可在词内断开。正文没有省略号、行数裁切或仅在鼠标悬停时显示的隐藏全文；触屏、键盘和无 JS 状态必须得到相同内容。只有表格、代码和宽公式允许在自身区域横向滚动，内容仍须完整可达。
- 装饰图与动效不承担文字内容；暂停按钮使用操作字阶和至少 44 px 高的触达区域。文章桌面目录随阅读位置高亮；手机目录用原生展开控件，条目允许多行。

维护规则：新增字阶或颜色需要先修改本文件，说明现有角色为什么不能承载，再改 `tokens.css`。`check-design-tokens.mjs` 限定角色集合、禁止无用途角色及非规范字重；浏览器矩阵检查 320–1440 px 的真实排版，截图需要人工审视换行、层级与节奏。检查通过不等于视觉得到作者认可。

## 版面

- 全站纸张最大宽度 1320 px，桌面内边距 52 px；细双层版框与四角套准记号贯穿正式页面。手机缩小版框与边距，但保留纸张感。
- `try/loom` 的朱色「佳杰」印放在全站页尾左角，保持原型的 74 px 方印、楷体和轻微倾角；手机缩至 62 px。首页首屏保留朱色小标，但用正式网站身份代替试样日期。
- 首页参照 `try` 的约 1.06 / 0.94 双栏开场：左侧作者介绍，右侧由真实作品图构成的台面。台面沿用原型的 6 条金色横线、4 条靛色竖线及图卡轻微漂浮；交织曲线只承担视觉细节，不宣称作品之间存在内容关系。提供暂停按钮，减少动态效果或禁用 JavaScript 时保持静态可读。
- 首页后段为一条可追溯来源的光线阅读路径，再给历法、山川及其他作品清楚入口。光是策展线索，网站仍是个人网站。
- 文章头沿左窄栏与宽标题轴排布。正文在整张纸上居中，宽度不超过 700 px；文章自有章节目录位于左栏，随滚动高亮当前章节，手机上折叠。右边不为已取消的批注预留空槽。正文段落、图片、公式与脚注遵循作者原文，不把第一张图自动认作题图。
- 其余页面复用纸张、窄边栏、标题字阶和细分隔线，内容索引保持原有真实路由与关系。局部视觉事件由真实图像和内容密度决定。

## 内容与交互边界

- 首页四站落点为冰晶光路、Lumice、光谱渲染、相机校正与白平衡分支。它们是阅读顺序，不声称研究时间上的因果；每站指向真实文章或项目和来源。
- 文章正文来自公开 Writing-Lab 快照，三种文章状态、11 篇作者全文、稳定路由、来源与分页保持有效。导读和衔接段落可编辑，但不得混进作者原文。
- 科学图完整呈现，不能裁掉坐标轴、图例或图注；示意图标明性质。图片可打开原图。
- 自然滚动、无 JavaScript 可读、键盘可达；手机目录用原生 `details`，探索关系的无 JS 回退继续可用。首页台面有可暂停的原型动画，离开视口或页面隐藏时停止运算，并尊重 `prefers-reduced-motion`。

## 验收

`npm run test:content`、`npm run check`、`npm run build`、`npm run test:site` 与浏览器矩阵检查是正确性门槛。首页、长文及内容索引必须在桌面、平板和手机上目视检查。自动检查不能代理作者的审美判断；发布前由作者在真实页面上裁决。
