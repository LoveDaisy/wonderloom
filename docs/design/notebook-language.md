# Wonderloom 正式视觉语言 · 纸上的光

适用于正式页面。视觉基准是 `try/loom` 的实际页面及 `scratchpad/explore-loom-direction/assets/loom/` 截图；`/directions/` 继续作为隔离的历史试样。2026-10-23 作者明确否决浅绿版本，要求原样沿用 `try/loom` 的配色和主要版式。此裁决优先于此前的设计结项报告。

## 材料与色值

`src/styles/tokens.css` 是正式页面的唯一权威。以下值取自 `try/loom:src/styles/loom-try.css`，不另行调色：

| 材料 | 色值 | 用途 |
| --- | --- | --- |
| 纸 | `#F4EFE1` | 页面底色，沿用原型的 `grain.png` 纸纹 |
| 浅纸 | `#FAF7EC` | 次级纸面 |
| 深纸 | `#E9E1CD` | 极少量衬底 |
| 墨 | `#23282E` | 正文、边框及主标题 |
| 朱 | `#B03A2E` | 当前态、编号、小面积强调 |
| 靛 | `#2C4A63` | 文字链接 |
| 金 | `#C79A3A` | 交织曲线等非承重装饰；不在浅纸上承担正文对比度 |

边线用原型墨色透明度，图像白边沿用原型的纸片处理。不要重新引入浅绿配色、渐变底、玻璃效果或通用圆角卡片。宋体承担标题和长文，黑体承担导航与操作，楷体仅用于极短的手写感标记，等宽用于编号与来源。

## 版面

- 全站纸张最大宽度 1320 px，桌面内边距 52 px；细双层版框与四角套准记号贯穿正式页面。手机缩小版框与边距，但保留纸张感。
- 首页参照 `try` 的约 1.06 / 0.94 双栏开场：左侧作者介绍，右侧由真实作品图构成的台面。台面沿用原型的 6 条金色横线、4 条靛色竖线及图卡轻微漂浮；交织曲线只承担视觉细节，不宣称作品之间存在内容关系。提供暂停按钮，减少动态效果或禁用 JavaScript 时保持静态可读。
- 首页后段为一条可追溯来源的光线阅读路径，再给历法、山川及其他作品清楚入口。光是策展线索，网站仍是个人网站。
- 文章头沿左窄栏与宽标题轴排布。正文在整张纸上居中，宽度不超过 700 px；文章自有章节目录位于左栏，随滚动高亮当前章节，手机上折叠。右边不为已取消的批注预留空槽。正文段落、图片、公式与脚注遵循作者原文，不把第一张图自动认作题图。
- 其余页面复用纸张、窄边栏、标题字阶和细分隔线，内容索引保持原有真实路由与关系。局部视觉事件由真实图像和内容密度决定。

## 内容与交互边界

- 首页四站落点为冰晶光路、Lumice、光谱渲染、相机校正与白平衡分支。它们是阅读顺序，不声称研究时间上的因果；每站指向真实文章或项目和来源。
- 文章正文来自公开 Writing-Lab 快照，三种文章状态、11 篇作者全文、稳定路由、来源与分页保持有效。导读和衔接段落可编辑，但不得混进作者原文。
- 科学图完整呈现，不能裁掉坐标轴、图例或图注；示意图标明性质。图片可打开原图。
- 自然滚动、无 JavaScript 可读、键盘可达；手机目录用原生 `details`，探索关系的无 JS 回退继续可用。首页台面有可暂停的原型动画，离开视口或页面隐藏时停止运算，并尊重 `prefers-reduced-motion`。

## 验收

`npm run test:content`、`npm run check`、`npm run build`、`npm run test:site` 与浏览器矩阵检查是正确性门槛。首页、长文及内容索引必须在桌面、平板和手机上目视检查。自动检查不能代理作者的审美判断；发布前由作者在真实页面上裁决。
