# 研究手记 · 设计语言 v0.2

适用于 A 方向的首页、文章、探索与设计语言试样。作者已选择 A 的气质，本轮验证统一性；审美效果仍待作者反馈。B 保留作为第一轮参考。

## 字体与层级

中文标题使用宋体栈（Songti SC / Noto Serif CJK SC），正文和操作使用系统黑体栈（PingFang SC / Microsoft YaHei）。西文随既有 serif / sans 字族回退。不引入第三种装饰字体，不用斜体、竖排小字或局部加粗区分章节。

| 角色 | 桌面 / 手机 | 字体 · 字重 | 行高 | 用途 |
|---|---|---|---|---|
| 页标题 | 48 / 28 px | 宋体 · 400 | 1.5 | 每页唯一 h1 |
| 内容标题 | 28 / 24 px | 宋体 · 400 | 1.6 | 主要问题、文章分组、关系说明标题 |
| 条目标题 | 22 / 20 px | 宋体 · 400 | 1.6 | 文章、系列、阅读路径、关联作品 |
| 正文 | 16 / 16 px | 黑体 · 400 | 1.9 | 导读、段落、普通链接 |
| 辅助文字 | 13 / 13 px | 黑体 · 400 | 1.75 | 图注、来源、索引、分类、状态 |

页边章节标题使用正文档的黑体 500；导航当前状态也只升到 500。字标是品牌资产例外，沿用其字形，尺寸使用内容标题档。语义层级与视觉角色分开：页边 h2 不应因为是 h2 就放大成正文标题。

首页“从一个问题开始”“另一些好奇心”“沿着一个问题走得远一点”均为同级的页边章节标题。它们不依次升级字号；真正的问题标题在正文栏内使用内容标题档。

## 网格与节奏

- 整体最大宽 1120 px；页眉、正文、页脚共用左右边界。
- 桌面：176 px 页边栏 + 48 px 栏间距 + 自适应正文。≤1100 px：144 + 32；≤760 px：单列、左右各 24 px。
- 两条主轴：页边索引左缘与正文左缘。页标题、问题标题、正文、图像外缘、图注、旁注均以正文轴起排。标题不再逐行缩进。
- 段落间 16 px，标题与内容 / 同组信息间 24 px，条目内分组 32 px，独立条目间 48 px，章节内边距 64 px，页尾留白 96 px。基础单位 8 px。
- 手机把页边索引放在正文之前，消除空栏；正文与辅助文字不继续缩小。
- 编号放入预留的栏间空隙；标题和导读不再为了编号整体右移。步骤列表同理。手机编号进入流内，标题仍从主轴起排。

## 图版、旁注与表面

- 纸色为页面底色，黛蓝为正文，缃色只用于当前状态。辅助灰仅用于来源、标签等辅助信息，不把所有段落降成灰色。
- 科学图完整展示，使用 contain；不裁切、不滤色。图框使用统一的内距；图像自身的黑色或白色底保留。无圆角、投影或装饰性边框。
- 图注在图框外，左缘回到正文轴。来源另起一行，同为辅助文字档；不再出现比图注更小的第三档文字。
- 普通旁注（“这页的另一端”）是正文流中的补充段，使用一条分隔线和辅助标签，不使用带内缩的色块。
- 关系选择器的选中底色向页边留白延伸，文字仍对齐索引轴。解释区沿正文轴排版，不再嵌套一层带 padding 的卡片。
- 章节之间使用细分隔线，条目之间优先使用空白；线条不围合成卡片网格。

## 交互

原生滚动、标准锚点与文字链接。图像可打开完整图；键盘 focus 明确。关系选择保留按钮、选中状态和读屏播报，无 JavaScript 时回退为原生 details。移动端作品选择使用可换行的文字选项，保持至少 44 px 的触达高度。尊重 reduced-motion。

## 实现与后续约束

- 数值唯一入口：`src/styles/tokens.css` 的 `.notebook` 作用域。
- 文字角色唯一入口：`src/styles/notebook.css` 的开头部分；组件布局不得另写字号或字重。
- 页边/正文结构共用 `.nb-grid`；复用字号不要求所有区块采用相同版式。
- 可见样张：`/directions/research/notebook/language/`，使用与真实页面相同的 CSS。
- 新组件先选择已有文字角色、对齐轴、间距。确需例外时，先在本文件说明，再修改 token；不继续累加局部补丁。
