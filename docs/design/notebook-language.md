# 浅光阅读 · 设计语言 v2.0

适用于 Wonderloom 的正式页面。`/directions/` 是只读历史试样，不参与正式视觉系统或导航决策。

## 核心构成

- 页面是浅灰绿纸面上的连续阅读，不做全屏舞台、滚动吸附、悬浮导航或滚动驱动装饰。
- 首页以一句可直接理解的话与真实 Lumice 模拟图起笔，随后把“冰晶光路 → Lumice → 光谱 → 相机校正 / 白平衡”排为一条可返回原文的阅读线。后两者是并列分支，不写成单一因果。
- 时间、山川与光并列进入入口；`loom` 只保留在品牌名与关于页的必要说明，不承担页面叙事。
- 科学图是证据而不是背景纹理：完整显示、不裁切、不滤色，图注与作者/来源随图同行。

## 字体、色彩与节奏

中文标题使用 `Songti SC / Noto Serif CJK SC / STSong` 等宋体回退栈；正文、导航和操作用系统黑体栈。只用这两种文字角色，不引入仅覆盖拉丁字符的展示字体。

| 角色 | 桌面范围 | 手机范围 | 用途 |
| --- | --- | --- | --- |
| 首页标题 | 48–92 px | 42–49 px | 与真实模拟图共同构成开场 |
| 页标题 | 41–74 px | 41 px 起 | 每页唯一 h1 |
| 段落标题 | 23–61 px | 23 px 起 | 阅读线、目录、文章层级 |
| 正文 | 16–21 px | 16 px | 导读与正文 |
| 来源、编号 | 12–14 px | 12–14 px | 只作必要的辅助信息 |

Token 的唯一来源是 `src/styles/tokens.css`：浅灰绿 `--paper`、近黑绿 `--ink`、深绿 `--accent`、低对比绿灰 `--line`。`--rail-width` 与 `--rail-gap` 定义内容页共用的边栏网格；`--content-section-space` 与 `--home-section-space` 定义两类段落节奏；`--type-display`、`--type-page`、`--type-section`、`--type-feature`、`--type-entry`、`--type-subentry` 和文章标题/正文、label/meta/caption 角色统一字体尺度。小屏只在 token 层覆盖对应角色，单个图版的独有尺寸仍写在组件规则中。不使用深色主题、霓虹、高饱和渐变、玻璃模糊、投影、圆角卡片或渐变文字。

页面最大宽度为 1200 px，左右边距由 `--gutter` 控制。长文正文收束到 720 px；目录和阅读线使用细分隔线加大留白，而非把每一项围成卡片。小屏改为单列，导航仍是自然文档流。

## 组件边界

- `BaseLayout` 是所有正式页唯一壳层，提供 metadata、canonical、跳到正文、普通文档流的页头和页尾。
- `site.css` 是正式样式唯一入口，拆为基础、内容、文章与首页四层；旧 notebook 样式只在冻结的 `directions-legacy*.css` 副本中存在。
- `LightHome` 从 `home.ts` 的工作 ID、来源 ID 和原始图片元数据取数据；标题、链接和出处不复制为另一份权威。首页配图来自相应已发表文章与项目，冰晶光路、光谱计算和相机响应不得用无关的天球或山川图占位。
- 内容网络继续以 `content-network.ts` 的显式 relation、topic 与 reading path 为准，不能从共享标签推导关系。
- 文章的三个发布状态、11 篇冰晕作者稿、路由和来源说明是内容契约，视觉层不得改写正文或暗示新的发表状态。

## 交互与可访问性

- 普通链接、锚点、图片原图链接和 explore 的作品关系选择是唯一必要交互；无 JavaScript 时，关系内容以原生 `details` 保持可读。
- 关系选择器有真实 button、`aria-pressed`、`aria-live` 状态和键盘焦点。所有交互都在当前内容中工作，不劫持滚动。
- 正式页面不自动播放动画。`prefers-reduced-motion` 显式关闭任何样式动画和过渡；焦点使用清晰的深绿轮廓。
- 图片须有替代文字、宽高与完整图入口。桌面与手机都不得出现横向溢出；标题可换行，但不截断。

## 验收

每次改动至少运行 `npm run test:content`、`npx astro check`、`npx astro build`、`npm run test:site` 和 `git diff --check`。浏览器检查首页、文章目录、作者全文、探索关系、项目、关于与 404 的 1440、768、390 宽度；同时确认 directions 历史样张仍只加载其冻结样式。
