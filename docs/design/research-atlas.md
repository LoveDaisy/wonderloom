# 个人研究手记与科学图谱 · 第一轮试样

2026-10-20。作者希望减少首页的模板感、内页的连续双栏表格感，让全站更接近个人研究手记与科学图谱。本轮提供可直接浏览的比较页面，供继续讨论，不替换正式路由。

## 比较入口

`/directions/research/`，两套各有 `home/`、`writing/`、`explore/`：

- A：`/directions/research/notebook/…`。连续阅读、页边注、图文与索引共享对齐线。
- B：`/directions/research/atlas/…`。模拟图与科学图先建立印象，主题编排与可选作品关系提供探索入口。

顶部切换保留当前页面类型；文章、系列、项目及阅读路径链接进入现有真实内容。试样与对照总览均 `noindex, nofollow`，无正式 canonical。

## 两套设计判断

### A · 研究手记

概念：把探索一个问题时的正文、图版和旁注，变成网站的版面结构。

- 首页从作者的两行开场进入一个具体问题；边注承担阅读位置与关联提示。
- 文章按问题分为两组连续目录，保留八篇完整题名与导读。
- 探索页以阅读路径与作品索引为主；选中作品后，同页显示关联理由。

### B · 科学图谱

概念：让作者实际计算出来的图像成为目录，让人工确认的作品关系成为经纬。

- 首页以真实图像的大小与排列决定主次，暗底承接冰晕图的观看环境。
- 文章页以两组主题及不同图文密度形成编排，不给每篇文章包同构卡片。
- 探索页的线只来自 `content-network.ts` 中的显式关系；选中作品强调直接邻接线并显示解释。
- 手机上把空间图谱转为可换行的作品选择器；正文与关联理由仍完整可读。

## taste-skill 的使用边界

已安装 `design-taste-frontend`，使用项目材料盘点、方向比较与截图批评方法。保留作者已经确认的配色、中文字体及自然滚动；不以动效数量、摄影数量、全面禁止细线/目录编号等作者偏好替换项目判断。

方向抽样给出 `split-stage`、`type-only-statement`、`contact-sheet`：固定半屏与原有自然滚动选择不符；大量小图不适合只有四幅核心科学图的内容条件；纯文字宣言可参考其主次，但不采用广告式超大字号。因此两套以已获作者认可的“研究手记与科学图谱”概念组织，不声称完整采用某个随机方向。

工具的 `inspect.mjs` 在独立 Chrome 的 `Page.navigate` 阶段超时，没有产出报告。实际验收使用已安装的 Playwright/Chrome 完成。没有声称通过该 skill 的原始评分门槛。

## 数据与实现

- `src/data/research-editions.ts` 只存方向、展示分组的内容 ID 与图谱位置；题名、导读、路径、关系继续共用现有 catalogue。
- `ResearchLayout.astro` 和 `research-editions.css` 隔离试样表现；既有正式页的布局和样式不改。
- 作品选择只做本地视图更新。无 JavaScript 时隐藏不可用选择按钮，保留十一份原生 `details` 和可用链接。
- 选择按钮支持键盘、`aria-pressed`、`aria-controls`；状态通过 live region 通知。
- 所有新增视觉过渡遵守 `prefers-reduced-motion`；不添加滚动监听、滚动停靠或固定整屏。
