作者认可第三轮其余部分，希望首页恢复原先“两组曲线交织”的图形，像绸缎一样缓慢舞动。本轮只替换 A 首页的头图。

- 点击图案或使用键盘可以暂停、恢复。离开视口或进入后台停算；无 JavaScript、减少动态效果时保留原始静态图。
- 六种宽度静态检查、桌面与手机的动画/键盘暂停/离屏暂停/实时切换动态偏好，以及无 JS 回退均通过，无脚本错误。已查看桌面、手机首屏和三个动态时刻的截图。
- `npm run check`：59 文件无错误、警告或提示；构建 37 页；站点检查 1169 个本地链接与资源通过。其余部分的代码与布局规则保留第三轮，截图比对记录在 `qa/round4/`。

## 两套设计判断

### A · 研究手记

概念：把探索一个问题时的正文、图版和旁注，变成网站的版面结构。

- 首页从作者的两行开场进入一个具体问题；边注承担阅读位置与关联提示。
- 文章按问题分为两组连续目录，保留八篇完整题名与导读。
- 探索页以阅读路径与作品索引为主；选中作品后，同页显示关联理由。

### B · 科学图谱

概念：让作者实际计算出来的图像成为目录，让人工确认的作品关系成为经纬。

- 首页以真实图像的大小与排列决定主次，暗底承接冰晕图的观看环境。
- 文章页以两组主题及不同图文密度形成编排，不给每篇文章包同构卡片。
- 探索页的线只来自 `content-network.ts` 中的显式关系；选中作品强调直接邻接线并显示解释。
- 手机上把空间图谱转为可换行的作品选择器；正文与关联理由仍完整可读。

## taste-skill 的使用边界

已安装 `design-taste-frontend`，使用项目材料盘点、方向比较与截图批评方法。保留作者已经确认的配色、中文字体及自然滚动；不以动效数量、摄影数量、全面禁止细线/目录编号等作者偏好替换项目判断。
