## 1. 来源：作者给的三条约束

本轮作者明确要求「忘记以往的约束，只从这三条出发」（以往 `scratchpad/explore-loom-direction/loom-direction.md` 的不做清单只是历史失败记录，可以参考，但不是禁令）：

1. **编织**：从 Wonderloom（wonder + loom）出发，有编织的意象。用在动图、纹理还是线条不限定。
2. **复古 + 科技**：一种思路是配色/字体体现复古，排版/动效体现科技。
3. **叙事**：首页和探索注重叙事。作者的思考方式是把问题拆到底层原理，用自己的视角重新理解，再组装回去（费曼式）。可以体现，但不在页面上标榜「费曼式」。

作者对本轮结果的评价（原话摘录）：「整体布局确实更好看了」「探索页比以前的好很多」「这个绕线画的点子很棒」「悬停预览……这个效果很棒」。

## 2. 原则

1. **线在承载信息时才是主角，不是全站必备花纹。** 编织意象必须承载信息或可操作：绕线板上每根线是一条规则的结果；探索页每根线是一条阅读路径或一条人工记录的联系；首页「一条光的线索」的纬线把四站串成顺序。其余页面主要继承纸、墨、字与阅读节奏；只有内容确有顺序或人工记录的联系时才使用线与节点。不承载任何东西的线条一律不加。
2. **拆开再装回去，用形式演出来，而不是用字说出来。** 绕线板：每根都是直线，弯的是它们一起围出的包络——简单部件、简单规则，装回去出现了谁也没画的曲线。这是全站叙事姿态的缩影。
3. **一种记号只表示一件事，全站一致**（§4）。两处长得不一样的记号，读者会以为它们意思不一样；同一意思用两套样子就是零碎。
4. **复古落在材料，科技落在结构与计算。** 纸、靛、朱、Didone 数字、宋体、算筹、钉圈刻度是材料；可调参数的实时计算、带读数的仪器感控件、经纬结构的信息图是科技。不用霓虹、玻璃拟态、赛博风。
5. **首屏先对外行成立。** 不懂任何背景的人看到的应该是「好看、会动、能玩」；想深究的人才去读图下两三行说明。被否决的晒图版正是反例（§10）。
6. **全站只有一个持续动效**（首页绕线板）。其余动效只回应读者的动作：悬停、聚焦、点击、拖动。不做滚动触发的入场动画。
7. **整页轻。** 纸色为底，大面积深色块会压住整页（§10）。重量用字号、线的密度和留白制造。

## 6. 动效与交互

- **签名动效只有一个**：首页绕线板。其他元素不自动动。
- **交互回应动作**：悬停变色约 0.2s；探索页选中/预览时关系线从一端「织」到另一端（`pathLength=1` + `stroke-dashoffset` 动画，0.5s）。
- **悬停 = 预览，点击 = 钉住。** 预览只改图，不改说明面板（面板在右侧，鼠标移过去的途中必然扫过别的条目，跟随悬停就永远停不到目标上）。鼠标离开图区、或焦点离开，回到钉住的状态。键盘聚焦等同悬停。
- **持续动效的义务**：最高 30fps；离开视口或页面转入后台时停算；有暂停按钮；`prefers-reduced-motion: reduce` 时静止在一个有意义的帧上（绕线板停在 k=2），手动控件仍可用；没有 JavaScript 时给静态 SVG。
- 不用滚动停靠、整屏分幕、滚动触发的入场动画。这不是旧禁令的延续，而是第 6 条原则：整站只留一个持续动效。

## 7. 首屏绕线板（`StitchBoard.astro` + `scripts/stitch-board.ts` + `lib/curve-stitch.ts`）

- **数学**：圆周上 `PEGS = 200` 枚钉子，起点在左（`START = π`）。第 n 根线从角度 `START + 2πn/N` 连到 `START + 2πkn/N`。整数 k 时，直线族的包络是有 k−1 个尖点的外摆线：k=2 心脏线，k=3 肾形线。非整数 k 时连续变形。
- **节奏**：k 在 `2→3→4→5→6→5→4→3→…` 之间循环，每个整数停 4.2s，过渡 4.8s，用 smoothstep 缓动。读数在整数附近（±0.02）显示曲线名并转朱色，其余时间显示「在两个整数之间」。
- **线色**：线条颜色沿钉子序号在 `--cy-prussian-ink` 与 `--cy-vermilion` 之间余弦往复，透明度 0.3，线宽 0.8px。线越密越深，包络因此显形。
- **拨弦**：用指针位移线段与每根线做相交判断，相交即拨动：振幅 `min(12, 3 + 速度×0.35)`，衰减时间常数 0.9s，4Hz，用二次贝塞尔中点偏移画出。仅限指针设备；`touch-action: pan-y` 保证手机竖向滚动不被拦截。
- **控件**：*k* 滑杆（2–7），拖动即暂停自动播放；暂停/继续按钮。
- **说明文案的事实核对**：「k = 3 时的肾形线，就是阳光照进咖啡杯、杯底那道亮弧的完整样子」——平行光在圆形镜面里的反射焦散是肾形线，杯底看到的是它的一半。心脏线对应的是点光源位于圆周上的情形，所以文案没有把心脏线说成咖啡杯。改文案时不要把两者混淆。

## 8. 探索页经纬图（`CyanExplore.astro` + `scripts/explore-loom.ts`）

- **数据**：两条阅读路径来自 `home.paths`（`content-network.ts` 的 `readingPaths`）；联系来自 `relations`；主题来自 `topics`。不从共享标签推导任何关系。
- **几何**：三栏 `[A 标题 1fr][SVG 220px][B 标题 1fr]`，行高 96px。A 线在 x=36，B 线在 x=184。A 列标题右对齐，B 列左对齐，两列镜像。
  - 同一路径内非相邻的联系画成弧：A 向右鼓、B 向左鼓，鼓出 `16 + 15×跨度` px。
  - 跨路径的联系画成两线之间的三次曲线，平时是虚线。
  - 相邻站之间的联系与经线重合，平时不画，选中时沿线高亮。
- **状态**：
  - 全部：无高亮。
  - 主题（钉住）：主题内的作品是 related（节点填靛），其余淡化到 0.32；两端都在主题内的线亮起。
  - 作品（钉住）：它本身是 selected（朱色实心），与它相连的是 related（朱色描边），相连的线亮起；右侧面板显示类别、所在路径与站次、摘要、打开链接，以及每条联系和原因。
  - 预览：悬停或聚焦时临时套用「作品」的高亮，面板不变。
- **点击**：宽屏下第一次点击钉住，再点一次打开；按住修饰键点击直接按浏览器默认行为打开；Esc 取消钉住。窄屏（<900px）隐藏 SVG 和面板，两条路径各自变成左侧竖线列表，点击直接打开。
- **无 JS**：不显示主题按钮，面板显示「怎么读这张图」，作品本身是普通链接。

## 9. 文案

- 站点编辑文案写在 `src/data/home.ts` 等数据文件里；正文页不加原文没有的字。
- 用读者的话命名，不用系统的话：写「已写 11 篇」「6 站，从上往下读」，不写「章节数」。
- 链接文字写清点了会发生什么：「读本站导读」「进入系列」「打开这个项目」。新组件不在链接后加「→」。旧组件里有些箭头被 `check-site.mjs` 逐字断言，见 §12。
- 首屏说明要先让外行看懂画面，再给一个具体、准确、能联系到生活经验的知识点；科学说法必须逐句核对（§7）。

## 10. 已否决：晒图版首屏（2026-10-28）

第一版首屏是一整块普鲁士蓝图版：左边实时追踪光线穿过转动的六角冰晶，右边按偏折角累加出 22° 晕，下方一排读数。物理上是对的（最亮处 21.95°），但被作者否决，原话：

> 首页首屏的动图感觉很突兀，一方面这里有一大块蓝色，和网站整体的纸色对比很强烈，显得很重；另一方面……这个图太直白，不够酷炫，但又不够古朴……对于没有相关背景的用户来说，这个图在这里又有点意义不明，让人困惑。

从中得到三条判据，已写进 §2：不要大面积深色块；首屏要么古朴、要么惊艳，「科学示意图」两头都不占；首屏要对外行先成立。代码已删除，可在 `try/cyanotype-loom@a44416b` 查看。

## 12. 收口与验收

1. **材料与入口**：正式调色板及共用别名只在 `tokens.css` 定义；`site.css` 引入 `site-loom.css`、`site-loom-content.css`，`BaseLayout` 不再接收 `theme`。正式页不再依赖 `.theme-cyanotype`。

3. **清理边界**：仅移除无引用的旧首页、旧正式内容样式与过时组件；历史 `/directions/`、它们实际依赖的 `research/*` 与独立 CSS 保留。删除历史公开路由需作者另行裁定。
4. **测试**：`check-site.mjs` 核对构建后探索页实际可达的作品、路径与主题链接，并保留来源、章节、作者全文和 canonical/noindex 约束。`check-design-tokens.mjs` 校验新调色板及正文参数。
