# 内容蓝图：从作品到阅读网络

> 更新：2026-10-19。本文件记录已确认的内容组织原则、这一轮实际落地的切片，以及不冒充当前能力的后续方向。

## 已确认的方向

Wonderloom 不按发布日期把所有内容排成一条队列。文章、程序和将来的单页工具可以同时属于多个主题；清楚的系列仍然保有自己的章节顺序；读者也可以沿人为设计的路径，在不同类型的作品间移动。

网站的职责分开：

- 首页用问题和少量作品给出入口；本轮在末章放入两条阅读路径，不替代历法、山川和原有入口。
- 探索页显示本轮明确收录的主题、关系和路径。关系都由人工说明；共享主题不自动变成一条连线。
- 文章页容纳系列导读与单篇导读；冰晕 series 还容纳从公开 Writing-Lab 单向生成的作者稿全文。导读是本站编辑文字，作者稿标题和正文由源仓权威决定。
- 项目页区分本地软件和研究代码。Lumice 的 bench 是性能看板，绝不是在线 Demo。

导航为“首页 / 探索 / 文章 / 项目 / 关于”。系列仍可从文章页按既有顺序阅读；顺序只属于相应系列或路径，不是全站唯一的阅读法。

## 首页的五条候选叙事

首页以问题带出作品，让读者从具体的拆解、推导与重建中感受到作者的视角，不使用“费曼式”自我标签。

| 入口问题 | 连接的内容 | 当前安排 |
| --- | --- | --- |
| 天空中的光环从哪里来？ | 现代冰晕研究、Lumice、Lumice-Integral，以及光谱颜色 | 当前最完整的主线 |
| 光怎样成为我们看见的颜色？ | 色觉、色彩空间、光谱渲染、白平衡、相机颜色匹配 | 本轮阅读路径 |
| 能从零开始设计一架望远镜吗？ | 几何光学、像差、光学系统设计 | 后续扩充 |
| 日月的运行怎样成为日历？ | 重新发明农历、天体周期与模型 | 保留现有入口 |
| 一座山的巍峨能怎样理解？ | 寻找高山、地形与量化视角 | 保留现有入口 |

它们是可调整的首页策展入口，不是互斥目录。光谱渲染可以同时连接冰晕、色彩科学和计算机图形学；未来“光学”主题也可以容纳像差系列、零散文章及项目。主题按内容需要逐步加入，不预先建立庞大的分类层级。

清楚的系列与跨作品阅读路径都有独立页面，并在主题页聚合；路径归入“探索”，不再增加一个顶层“叙事”导航。标签表达涉及的领域，路径表达推荐的阅读顺序，具体关系说明两件作品为什么值得放在一起。

## 这一轮的实际切片

本轮把“冰晕—光谱渲染—色彩科学”作为能真实浏览的起点：

- 主题：冰晕、光谱渲染、色彩科学；
- 路径：理解和重现冰晕、从光谱到颜色；
- 独立导读：绘光、冰晕第 0 篇和第 6 篇，及色彩空间、表示与转换、光谱渲染、白平衡、相机颜色匹配共 8 篇；
- 项目：既有 Lumice 与新增 Lumice Integral。后者是研究与参考代码，不暗示其为产品或在线服务。

图谱采用固定布局的原生 SVG 链接和等价的关系列表。链接能直接被键盘激活；没有 JavaScript 时，节点和列表仍可访问。脚本可按主题高亮，但不会把无关节点隐藏或从键盘焦点中移除；减少动态效果时没有持续动画。

## 内容与证据边界

文章记录只保存 `sourceId`，标题和 URL 只由 [`src/data/content-sources.ts`](../src/data/content-sources.ts) 解析。旧系列的 17 个章节也已转为同一来源引用；未进入单篇导读的章节仍是可见、明确的外链目录。

[`src/data/source-evidence.ts`](../src/data/source-evidence.ts) 是独立于来源清单的核验快照：它记录已发表快照或系列目录的定位，为全部 23 条来源保留核验日期和 SHA-256。构建时逐项核对 source ID、标题和 URL；缺少来源、篡改 URL、关系端点或路径节点都会使构建失败。来源细节和图片边界见[内容来源](content-sources.md)。

本站只导入 Writing-Lab 中 `directors-cut + published` 的冰晕作者稿，不导入草稿、outline 或 note；生成目录不是第二编辑源。第三方照片、未确认公开的源码或历史网页愿景不当成当前内容。科学图不裁掉坐标轴或图例，不用滤镜改变含义。

## 渐进迁移与第一发布源

当前阶段的单篇页面是稳定的导读 URL，不伪装成全文。以后迁移某篇全文时，应在同一 URL 加入经明确选定的公开版本，保留原始来源和迁移说明；不维护两份互相漂移的正文。

新的文章将以本站作为第一发布源：在这里维护唯一编辑源和稳定 URL，再按需要向外部平台转载，并标注转载出处。此目标不等于已迁入旧文，也不改变现有知乎原文的署名和链接。

## 后续候选（未在本轮实施）

以下方向有价值，但均不是当前网站声称已经具备的功能：

1. 逐篇迁移经确认的公开全文；
2. 为像差、历法、山川等主题补充独立路径；
3. 把新的工具或实验在真实可用后加入网络；
4. 在作品规模增加后重新评估图谱密度和筛选方式；
5. 再决定 Feed 或内容管理流程是否真正需要。
