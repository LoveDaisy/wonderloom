# 首版验收记录

日期：2026-10-17。范围：本地生产构建与浏览器预览，不代表公网部署验收。

## 自动检查

- `npm run check`：21 个文件，0 errors / warnings / hints。
- `npm run build`：9 个静态页面（含 404）。
- `npm run test:site`：9 页，146 个站内链接/资源引用检查通过；同时检查单一 H1、中文语言标记、图片 alt/尺寸，以及本地路径与 Obsidian 图片语法泄漏。
- 反例测试：把首页的一个内容 ID 临时替换为不存在的 ID，构建以非零状态退出，并明确报告 `Home featured: missing content reference`；随后恢复内容并重新构建、检查通过。原始失败日志留在 `.review/missing-reference-test.log`。

## 浏览器验证

完整结果见 [browser-checks.json](browser-checks.json)。

- 8 个正常路由 × 1440 / 768 / 390 / 320px = 32 组检查：均为 HTTP 200，无横向溢出、无损坏图片、各页仅一个 H1。
- 实际点击：首页 → 历法导读 → 章节链接；项目列表 → Lumice → 冰晕系列，站内链路正常。
- 章节原文 href 与公开快照逐条核对。手机上新增「查看章节目录」锚点，避免必须先滚完导读。
- 完整图片链接已点击，可打开本地原图。
- 不存在的路由返回 HTTP 404，并展示自定义页面；「回到首页」可用。
- 键盘首个 Tab 到达跳过导航链接，焦点可见；主导航可操作，当前栏目有标记。
- `prefers-reduced-motion: reduce` 下滚动行为为 `auto`。
- 主要三种文字色与三个背景色的 9 组对比度均至少 4.5:1（精确结果在 JSON 中）。
- 无页面 JavaScript 异常。测试不存在路由产生的 HTTP 404 为预期结果；直接打开原图时浏览器请求的 `/favicon.ico` 已补齐。
- 已人工查看桌面首页、手机首页、冰晕系列桌面页及历法系列手机页截图，并修整章节跳转和番外序号排版。

## 外部链接边界

- Lumice 性能看板 HTTP 抽查为 200。
- 三个系列的知乎首篇从命令行 HEAD 请求均返回 403，不能据此宣称外部阅读已完成端到端验证；这些 URL 已由本人已发表快照核对。浏览器是否需要登录/受到知乎平台限制，属于外部阅读边界。
- `find_peak` 仓库核实为非公开，因此首版不提供它的源码链接，也不单独列成可下载项目；地理题材以已发表文章呈现。
