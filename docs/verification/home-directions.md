# 首页视觉试样验收

日期：2026-10-18—19。范围：本地首页视觉方向比较，未部署。作者尚未选定最终视觉方向。

## 交付

- `/directions/`：三个方向的比较入口。
- `/directions/fieldnotes/`：A「好奇心手稿」，纸色、朱红、私人图版与页边标记。
- `/directions/observatory/`：B「午夜观测室」，墨蓝背景、缓慢运行的抽象轨迹、三张观测图手动切换。
- `/directions/loom/`：C「思想织机」，蓝橘配色、抽象织线、按钮切换交织方式。
- 三版均包括开场、三个探索问题、Lumice、系列阅读、作者与页脚；内容顺序相同。项目、系列链接继续进入第一版详情页。
- 原首页保留为基线；新路由标记 noindex。首页内容、collections、来源素材、原详情页与路由解析未改，无新增依赖。

## 验证

- `npm run check`：28 个文件，0 errors / warnings / hints。
- `npm run build`：13 个静态页面。
- `npm run test:site`：13 页、276 个站内链接与资源引用通过；验收脚本未放松。
- 比较页与三个试样 × 1440 / 768 / 390 / 320 px：16 组，HTTP 200、无横向溢出、无损坏图片、单一 H1。
- B 的三个按钮逐一经键盘空格激活：可见图版、按钮 pressed 状态匹配。关闭 JavaScript 时三张图全部可读，操作按钮隐藏。
- C 经 Enter 和点击切换织法；切换后四档宽度仍无溢出。
- 比较页 → A → 切换 B → 首页锚点 → 农历导读链路通过。
- `prefers-reduced-motion: reduce` 下零活动动画、滚动为 auto；首个 Tab 到达跳过导航链接，Enter 将焦点移至主内容。
- 检查三版文本的计算颜色与背景对比度；修正 C 深蓝项目区标题继承色，以及 A 项目区两处浅色小字。装饰符号对辅助技术隐藏。
- 无页面 JavaScript 异常。人工查看三个桌面整页与手机首屏截图。

浏览器结果见 [home-directions-browser.json](home-directions-browser.json)。本地截图与复查脚本位于被 Git 忽略的 `.review/directions/`。

## 设计与内容边界

既有研究图保持原始比例与完整内容，提供原图入口；没有滤色、裁掉坐标或冒充在线科学模拟。轨迹、印章与织线是代码绘制的抽象装饰，不是研究结果。

当前作品仅为首轮试选。内容与视觉独立，后续可以盘点全部可公开作品后重新策展。本轮验收仅确认试样可供比较；最终视觉选择及全站适配仍待后续讨论。
