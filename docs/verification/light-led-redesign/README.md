## 视觉裁定

2026-10-23 作者否决浅绿首版，指定 `try/loom` 的原始配色和主要版式为正式视觉基准。修订版原样取用纸、墨、朱、靛、金色值及原型纸纹，恢复版框与四图台面；光线四站仍依真实文章与项目组织。作者走查后指出正式台面的细静态曲线逊于原型，因此恢复原型的 6×4 粗线曲线与图卡漂浮，支持暂停和减少动态效果；交织曲线仍不解释为作品之间的内容关系。文章正文居中、不留右侧批注空槽，手机目录改为原生折叠，桌面与手机目录会随阅读位置高亮章节。此次否决说明前一轮正确性与代码评审通过并不能替代作者审美验收。

再次走查时，作者指出「使用了朱色色值」并不等于保留原型的朱色视觉：此前首屏缺少朱色标记，也漏掉了页尾左角的「佳杰」印。现已按原型恢复这两个位置，首屏小标改写为正式网站身份，页尾印章贯穿所有正式页面；朱色继续用于编号和当前态，避免扩成正文底色。

- npm run test:site：设计 token 与 `try/loom` 原始色值检查、11 篇/66 图的摘要校验及 46 页、1500 个本地链接/资源通过；文章状态、来源、系列顺序和显式关系检查通过。
- git diff --check：通过。

作者走查修订后，再以本地干净的 Writing-Lab checkout `b7784b8c96c742ee4f49f2277fe424bfda213ae4` 同步同样的 11 篇/66 图：`npm run check` 为 95 文件 0 error/warning/hint，`npm run build` 生成 46 页，`npm run test:site` 检查 1500 个本地链接/资源。浏览器矩阵新增动态台面与滚动目录状态断言，54 组截图均通过、0 失败。

运行 node docs/verification/light-led-redesign/verify-browser.mjs http://127.0.0.1:4323 使用本机 Chrome 和 design-taste-frontend 的 CDP 客户端，对 54 个页面/视口组合留存截图与原始 DOM 记录（见 final/browser-matrix/report.json）。范围包含首页 1440×900、1024×768、768×1024、390×844、320×844、320×640；文章索引、系列、纯导读、纯全文、导读加全文、含 13 个公式和 6 张表的长文、探索、主题、路径、项目、关于、真实 404 全部覆盖 1440/768/390；历史首页、文章、探索旧样张也覆盖这三档。结果：每页一个 h1、无坏图、无页面横向溢出、无控制台异常；手机导航目标至少 44px；长文公式和表格保持 overflow-x: auto。

45 个正式模板/视口组合均以真实 Tab 依次检查跳过链接、站点标识、首页导航的焦点可见性及视口内位置，再以 Enter 验证导航；首页与长文的手机键盘截图在第三次 Tab 后、Enter 跳转前捕获，能看到完整的导航焦点框。另从页面初始状态逐次 Tab 到内容区，按 Enter 并检查结果：首页阅读路径进入目标页、探索选择按钮更新 `aria-pressed`/对应 details/播报状态、禁 JS 下同页 summary 原生展开、长文目录锚点定位、前后篇分页进入相应文章。归档记录含每条路径实际 Tab 次数、焦点和目标状态。另存首页禁用 JS 与 reduced-motion 截图：四站及 18 个链接仍可用，台面静态线条完整、暂停按钮隐藏。新增状态断言验证普通模式下曲线与图卡确实运动、暂停后停止，以及长文目录随两个不同章节滚动正确切换；`long-article-toc-active-1440.jpg` 展示实际高亮。404 HTTP 状态为 404。

历史隔离断言检查 ResearchLayout 的唯一 legacy import、冻结入口的三个 import、浏览器实际加载的 ResearchLayout 样式表，以及各视口的 body class、`--paper`、`--ink`、`--nb-page-size` 和 h1 与 8365dbc 基线一致。九组同视口截图已逐张目视比较，页面文案和版式一致；织纹本身有原有动画，不把截图像素一致当作冻结条件。基线运行需要从 8365dbc 启动预览，并预先同步相同的作者文章素材；命令见 capture-legacy-baseline.mjs。

首页冷缓存初始请求由 final/browser-matrix/report.json 原样记录：本次转移 137,461 B，没有重复 URL；基线记录为 55,909 B，差额 81,552 B。修订版首屏有四张真实作品图与纸纹；浏览器也可能在测量窗口内提前请求折叠线以下的图片，因此这些数字是各次本地运行的实测记录，不是严格同资源集合的对比。浏览器脚本将超过 1.5 MB 或出现重复资源 URL 设为失败条件，不将本地数字当作公网传输量。

首页 Inspector 首次修订的报告与截图在 final/home-inspection/，拍摄于恢复原型动画之前。其 12 个风格 FAIL 主要要求删除原型的纸色、版框、编号、等宽标注与纸片阴影，甚至建议重新抽取配色；这与作者指定的 `try/loom` 视觉基准直接冲突，因此如实归档，不据此改掉原型特征。当前功能、响应式与内容验收以 final/browser-matrix/ 的 1440/768/390/320 截图和 report.json 为准；审美仍由作者判断。
