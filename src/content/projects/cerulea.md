同一片天空，头顶与地平线的颜色并不相同；太阳渐渐低下去，颜色又会变化。如果把太阳的位置、空气的成分和观看的方向交给计算，能不能从中得到一片天空？

Cerulea 从不同波长的光出发，计算光在大气里的散射与吸收，再将得到的光谱转换为屏幕上的颜色。

## 它能做什么

- 设置太阳位置和大气条件，比较空气分子、气溶胶与臭氧等成分对天空光谱的影响。
- 用不同的辐射传输近似计算天空，包括一次散射与多次散射；不同近似有各自的适用边界。
- 将同一次天空计算呈现为透视、鱼眼或全景图，也可查看指定方向的颜色坐标。

上图采用晴空条件，太阳折射前高度为 3°，朝向太阳一侧。它展示的是给定场景的漫射天空，不是太阳圆盘或真实地景；下缘色块遵循不绘制地面的显示约定，不能当成地表模拟结果。

## 从光谱到一幅图

空气改变的是不同波长的光，而屏幕最终只能显示红、绿、蓝。两者之间还隔着色度计算、曝光与色调映射。上图固定曝光、未作色适应；显示压缩后的像素不等于原始光谱辐亮度，也不能直接当作相机照片。

这里有一条与[色彩科学](/explore/topics/color-science/)相通的线索：物理计算得到的光谱，怎样成为可显示的颜色？[《光谱渲染的几个例子》导读](/writing/articles/spectral-rendering/)可以作为阅读入口。

## 如何使用与理解边界

这是在本机运行的 Python 研究代码，使用 `uv` 管理环境。按仓库 README 安装后，通过 `uv run python -m skycolor.cli render` 设置场景并输出图像，或用 `chart` 查看颜色坐标；完整参数与生产图说明见仓库。

模型能用来拆解和比较影响颜色的因素，不承诺精确复现任意真实天空。现有近似仍有已知物理偏差，尤其是暮光绝对亮度与不同观测地点的比较。图像能呈现某种现象，不等于该现象已通过观测验证。
