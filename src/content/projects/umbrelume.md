月全食时，月亮走进地球的影子，却没有完全消失。仍有一部分阳光沿着弯曲的光路穿过地球大气，到达月球；不同波长在途中损失的比例不同，影子里便留下了颜色。

Umbrelume 从太阳光谱、大气折射与沿程消光出发，计算月球距离处的光谱照度，再把地影中的照明场显示出来。

## 它能做什么

- 追踪掠过大气不同高度的折射光路，计算空气、臭氧与气溶胶对透射光的影响。
- 查看从本影到半影的光谱、相对明视觉照度与颜色，比较开启和关闭臭氧吸收的结果。
- 改变月球在影子中的位置，以统一曝光显示月面屏，并保留原始光谱数据与参数记录。

上图使用 `opac` 双层气溶胶文献先验：自由对流层 2–12 km 与平流层背景 12–35 km，不是某次月食实测或拟合后的大气。月盘中心距影轴 2860 km；整幅图统一提高 12 档曝光，没有逐位置提亮。

## 这不是一张月食照片

月盘是放在影平面上的均匀中性屏，用来呈现照明场的变化，没有月海纹理、月壤反射谱或球面入射角明暗，也未计入地面观察者的大气。

显示白点取食外太阳光谱，经 Bradford 适应至 D65；高光经过共同最大通道压缩，负线性 sRGB 裁至零。+12 EV 只是这张图的显示选择，不是相机曝光或观测亮度标定。颜色采用明视觉近似，不预测暗适应时的观感。

从照度光谱到屏幕颜色，同样需要[色彩科学](/explore/topics/color-science/)中的色度计算与显示处理。[《光谱渲染的几个例子》导读](/writing/articles/spectral-rendering/)讨论的正是这一步：先算光，再说明怎样把光显示出来。

## 如何使用与理解边界

这是独立、离线运行的 Python 研究代码，不依赖天空模拟项目。需要 `uv` 与 Python 3.12；按仓库 README 执行 `uv sync --locked`，再用 `uv run lunar-eclipse simulate --out outputs/current` 生成光谱、剖面和月面屏示意。复现上图应使用仓库生产图说明中的完整参数，而不是只运行默认命令。

当前采用球对称标准大气和固定文献先验，尚未包含云、散射入射光或真实三维天气。已有观测对照仍有残差，不能据此宣称完整月食颜色、绿松石带或某次月食的绝对亮度已获验证。
