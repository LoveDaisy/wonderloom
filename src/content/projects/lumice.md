一片天空里可以出现许多种光环与弧。要解释它们，不仅要知道冰晶会折射光，还要知道光线如何进入晶体、经过哪些面，以及离开时会指向哪里。

Lumice 把这些条件变成可以设置、计算与观察的模拟。

## 它能做什么

- 设置晶体、姿态分布、光源与观察方式，追踪光线穿过冰晶的路径。
- 通过波长相关的光谱渲染呈现冰晕色彩。
- 处理多重散射场景，探索一次晶体相互作用以外的图案。
- 使用图形界面调整参数与查看结果，或通过命令行组织模拟。

## 理解与实现，来回走几步

项目以 C++17 实现，命令行与图形界面共享模拟核心。它既是一件用于生成图像的工具，也是研究光路与几何结构时可以反复对照的实验装置。

《现代冰晕研究漫谈》记录了与这些问题有关的探索。可以先看图，再读原理；也可以带着文章里的问题，回来做一次模拟。

## 如何使用

这是在本机运行的软件，不是浏览器里的在线模拟器。可以从 GitHub Releases 获取发布版本，或按仓库 README 构建。性能看板记录基准测试结果，不提供交互式模拟。
